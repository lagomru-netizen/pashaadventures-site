Privacy Policy

This website

pashaadventures.ru is an information page about the Pasha's Adventures cartoon series. It does not use cookies, analytics, advertising or any trackers, and it does not collect personal data from visitors — including children.

Pasha Publisher (Google API application)

“Pasha Publisher” is an internal tool used only by the owner of the Pasha's Adventures YouTube channel to publish the channel's own videos and read the channel's own statistics through the YouTube Data API and YouTube Analytics API. It is not offered to the public and does not access any other user's account.

The tool uses Google user data only for these purposes: uploading and editing the channel's videos, titles, descriptions, thumbnails, subtitles and playlists, and reading aggregated channel statistics (views, watch time, subscribers). Access tokens are stored privately by the channel owner. The data is not sold, shared with third parties, used for advertising or used to train AI models.

Pasha Publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

Our YouTube channel

The channel is set as “made for kids”. Viewing on YouTube is governed by YouTube's own policies; we do not receive personal information about individual viewers.
